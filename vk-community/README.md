## Как создать сообщество (5 минут)

1. Откройте [vk.com](https://vk.com) и войдите по номеру **+79154567448**.
2. Меню слева → **Сообщества** → **Создать сообщество**.
3. Тип: **Бизнес** / **Местная компания** (или «Салон красоты», если есть в списке).
4. Название: `LOCAL Beauty Studio | Зиларт`.
5. Тематика: **Красота, здоровье**.
6. После создания заполните разделы из файлов в этой папке:
   - `01-opisanie.md` — описание, статус, контакты
   - `02-privetstvennyj-post.md` — первый пост
   - `03-menyu-i-ssylki.md` — меню и кнопки
   - `04-posty-na-start.md` — стартовые посты
   - `05-nastrojki.md` — настройки сообщества
