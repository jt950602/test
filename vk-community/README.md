## Что сделать вручную в ВК (ключ сообщества этого не умеет)

1. **Закрепить** первый пост (приветствие).
2. Заполнить **статус** под названием:  
   `Салон красоты в ЖК Зиларт · м. ЗИЛ · ежедневно 10:00–22:00`
3. Добавить **ссылки**: сайт + онлайн-запись YClients.
4. Кнопка действия → **Открыть URL** →  
   `https://n456129.yclients.com/company:432160` (текст: «Записаться онлайн»).
5. Короткий адрес: например `vk.com/localbeautyzilart`.
6. Обложка 1590×400 и аватар.
7. Альбомы: «Работы мастеров», «Интерьер», «Команда».
8. Автоответ в сообщениях (текст в `03-menyu-i-ssylki.md`).
