## Важно про фото

Ключ сообщества **не умеет** заливать в раздел «Фотографии» (альбомы).  
Фото видны на **стене**. Чтобы появились в «Фотографии»:

1. ВК → сообщество → **Фотографии** → загрузите вручную, **или**
2. Пришлите **токен пользователя**-админа (не ключ сообщества) — тогда можно создать альбом «Работы» через API.

## Один клик вручную

1. Закрепите приветственный пост: **⋯** → **Закрепить на стене**
