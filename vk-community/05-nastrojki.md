# Рекомендуемые настройки сообщества

## Основное

- [ ] Тип: бизнес / местная компания / салон красоты
- [ ] Тематика: Красота, здоровье
- [ ] Возрастные ограничения: нет
- [ ] Стена: открытая (или «только для сообщества» + обсуждения)
- [ ] Комментарии: включены
- [ ] Сообщения сообщества: включены
- [ ] Кнопка действия: «Записаться онлайн»

## Разделы включить

- [ ] Товары / услуги — по желанию (можно дублировать ключевые услуги)
- [ ] Фотоальбомы: «Интерьер», «Работы мастеров», «Команда»
- [ ] Видео — по желанию
- [ ] Обсуждения: «Отзывы», «Вопросы»
- [ ] Ссылки: сайт + онлайн-запись
- [ ] Контакты + карта (адрес Щусева 2к1)

## Продвижение

1. Добавьте сообщество в блок ВК на сайте local-beauty.site (иконка / виджет).
2. Укажите ссылку на сообщество в WhatsApp/Telegram/визитках.
3. Попросите мастеров и постоянных клиентов подписаться и оставить отзыв.
4. Запустите таргет ВК на радиус вокруг ЖК Зиларт / м. ЗИЛ.

## Адреса для короткого URL (проверить свободен ли)

1. `localbeauty`
2. `localbeautystudio`
3. `localbeautyzilart`
4. `lbs_zilart`

- [ ] Включены сообщения + автоответ
- [ ] Кнопка «Записаться онлайн»
- [ ] Закреплён приветственный пост
- [ ] Опубликованы 3–4 стартовых поста
- [ ] Созданы альбомы «Работы» и «Интерьер»
- [ ] Запрошен короткий адрес
